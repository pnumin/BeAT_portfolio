# BeAT 웹앱 포트폴리오

첨부 레퍼런스의 파란색·라임색 컬러, 둥근 카드, 프로젝트 중심 레이아웃을 참고해 제작한 반응형 한국어 포트폴리오입니다.

## 포함 파일

- `index.html` — 사이트 구조와 한국어 콘텐츠
- `styles.css` — 반응형 디자인 및 일러스트
- `script.js` — 스크롤 등장 효과, 맨 위로 버튼, 연도 자동 표시

## 실행 방법

별도의 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 서버를 사용하려면 이 폴더에서 아래 명령을 실행하세요.

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000`에 접속하세요.

## 배포

정적 사이트이므로 GitHub Pages, Netlify, Vercel 등에 폴더 전체를 업로드하면 됩니다.
